## Overview

Tarkov Monitor Dashboard reads Escape from Tarkov's log files to build a real-time statistics dashboard showing raid survival rate, escape frequency, kills per raid, ruble earned per hour, and hotspot death locations. It aggregates session data over time to reveal trends in performance without requiring third-party server access.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Tarkov Monitor Dashboard** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Survival Rate** | Tracks raid survival and escape rates across all maps over time |
| **Kill Statistics** | Per-raid kill counts segmented by map and time of day |
| **Economy Tracking** | Ruble earned per hour and per-raid economy performance |
| **Death Heatmaps** | Aggregated death location heatmaps per map for hotspot analysis |
